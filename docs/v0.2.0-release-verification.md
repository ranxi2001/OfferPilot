## 真实供应商冒烟

在服务端配置的实际 OpenAI-compatible provider 上执行了一场混合面试。对持久化
snapshot 只读取非正文元数据，得到：

- focus 为 `mixed`，JD 与简历来源均存在；
- 4 轮答案均已提交，题型分布为 2 道知识题和 2 道项目题；
- 会话进入完成态并生成报告；
- 本场引用了 8 个私有知识文档；
- 对应服务日志中的模型链路请求均返回 HTTP 200，观察到的耗时范围约为
  38.5 至 170.8 秒。持久化结果快速读取产生的 46/50 ms 请求不计入该范围。

这是一场真实 provider smoke test，只证明主链路在该次运行中成功，不代表问题质量、
稳定性或延迟已经达到统计显著。固定 corpus、多次重复、人工双盲评分和分阶段 SLO
属于 [v0.3.0 优化方案](./v0.3.0-optimization-plan.md) 的发布门禁。
